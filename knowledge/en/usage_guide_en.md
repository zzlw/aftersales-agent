## Laptop Won't Turn On / Black Screen

1. Confirm the power adapter is connected and the charging LED is on;
2. Perform a power drain: disconnect the adapter, hold the power button for 15 seconds, then reconnect and power on;
3. Connect an external monitor to isolate a screen failure: if the external display works, the built-in panel or cable is at fault;
4. If the fan spins but the screen stays black, unplug all external devices (USB drives, docks) and restart;
5. If none of the above works, note the LED status and any beep pattern, then contact support for a hardware diagnosis.

## Loud Fan Noise / Overheating

- Fan speed-up under heavy load (gaming, rendering, antivirus scans) is normal behavior;
- Switch the thermal mode to "Quiet" in Lenovo Vantage;
- Dust buildup reduces cooling efficiency; a professional cleaning every 12–18 months is recommended (paid service at service centers);
- If the unit stays hot and loud while idle, check Task Manager for abnormal processes or request a diagnosis.

## Wi-Fi Connection Problems

1. Make sure Airplane Mode is off; toggle the wireless function with Fn+F8 (or the corresponding hotkey);
2. Disable and re-enable the wireless adapter in Device Manager;
3. Update the Wi-Fi driver via Lenovo Vantage → System Update;
4. Test both the 5GHz and 2.4GHz bands on your router;
5. If other devices connect fine but this laptop fails, reset the network stack: Settings → Network → Network reset.

## Keyboard Keys Not Working

- Clean debris between keycaps with compressed air first;
- If an external keyboard works but the built-in one fails, the keyboard hardware is likely faulty — a free replacement is covered under warranty;
- Widespread key failure with a history of liquid spill counts as accidental damage and is not covered; paid repair is available.

## System Recovery and Reset

- Built-in Windows reset: Settings → System → Recovery → Reset this PC (option to keep personal files);
- If the system cannot boot, press F11 repeatedly at startup (or use the Novo pinhole button) to enter the recovery environment;
- Always back up important data before resetting, and keep the power adapter connected during recovery.
