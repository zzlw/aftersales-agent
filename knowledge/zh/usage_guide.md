## 开机黑屏/无法开机

1. 确认电源接通、电池有电（充电指示灯亮）；
2. 长按电源键 15 秒强制关机后再开机（静电释放）；
3. 外接显示器判断是否为屏幕故障：外接有画面则为屏幕或排线问题；
4. 开机有风扇声但黑屏，尝试拔掉外接设备（U 盘、扩展坞）后重启；
5. 以上无效请记录开机时的指示灯状态与蜂鸣声，转人工检测。

## 风扇噪音大 / 机身发热

- 后台高负载（游戏、视频渲染、杀毒扫描）时风扇加速属正常现象；
- 在 Lenovo Vantage 中切换"智能散热"模式为"安静模式"；
- 长期未清灰会导致散热效率下降，建议每 12-18 个月做一次清灰保养（服务站提供付费清灰服务）；
- 若待机状态下持续高温高噪音，请检查任务管理器异常进程，或申请检测。

## Wi-Fi 连不上 / 频繁掉线

1. 确认飞行模式未开启，Fn+F8（或对应快捷键）开关无线功能；
2. 设备管理器中禁用再启用无线网卡；
3. 更新无线网卡驱动（Lenovo Vantage → 系统更新）；
4. 路由器 5GHz/2.4GHz 频段切换测试；
5. 其他设备连接同一 Wi-Fi 正常而本机异常的，重置网络设置：设置 → 网络 → 网络重置。

## 键盘个别按键失灵

- 先用压缩空气清理键帽缝隙异物；
- 外接键盘输入正常而内置键盘失灵的，多为键盘硬件故障，保修期内可免费更换键盘；
- 大面积按键失灵伴随进液史的，属人为损坏，不在保修范围，可付费维修。

## 系统恢复与重置

- Windows 内置重置：设置 → 系统 → 恢复 → 重置此电脑（可选保留个人文件）；
- 无法进入系统时：开机连续按 F11（或 Novo 一键恢复小孔）进入恢复环境；
- 重置前务必备份重要数据，恢复过程需保持电源连接。
